How to type

  1. Press the key that has the next letter on it, once for each letter of the word. The letters on a key are shown on the key.
  2. Likely words appear above the keys, in place of the Copy, Clear, Help and Settings buttons. Select moves to the next one. You can also tap a word: it is highlighted (or written at once, if you choose that in Settings).
  3. Press any letter key to write the picked word and start the next one. Until then the word is shown underlined in the text, so you can see how it will read.

Func

  • Func removes the last key you pressed.
  • With nothing typed, Func opens the function menu. In it, Func again deletes the last word and the key marked ↵ (Select) starts a new line.
  • If you do not need the function menu, press any of the top three keys to go back to normal typing. After you pick a word, Func writes it and opens the menu, so a second Func deletes that word: a quick way to fix a typo.
  • In the function menu the lower keys switch to abc (spell letters), 123 (numbers and signs) or .?! (punctuation). There, press the same key again to change its character, Select to accept it, and Func to go back. When nothing is waiting to be accepted, Select reads Exit and leaves the mode.

Keyboard

Each colour is one on-screen key. ` copies the text and Esc clears it.
